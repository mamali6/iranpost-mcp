# iranpost-mcp (v2) — سامانه جامع رهگیری مرسولات پستی و کوریرهای ایران

یک MCP Server هوشمند و بدون نیاز به پروکسی برای رهگیری انواع مرسولات در سامانه‌های هوش مصنوعی (مانند Hermes Agent، Claude Desktop و سایر کلاینت‌های پروتکل MCP).

این ابزار از **پست ایران**، **تیپاکس (Tipax)**، **ماهکس (Mahex)** و **کالارسان چاپار (Chapar)** پشتیبانی می‌کند.

---

## 🚀 ویژگی‌های جدید در نسخه v2
- **بدون محدودیت جغرافیایی و بدون نیاز به پروکسی (Proxy-Free):** به دلیل محدودیت‌های دسترسی به `tracking.post.ir` از خارج ایران، در نسخه ۲ درگاه مستقیم سامانهٔ رهگیر یکپارچه‌سازی شده است که بدون نیاز به پروکسی ایرانی و در کمتر از ۲ ثانیه پاسخ می‌دهد.
- **پشتیبانی از کوریرهای خصوصی:** علاوه بر شرکت ملی پست، امکان رهگیری مرسولات **تیپاکس**، **ماهکس** و **چاپار** اضافه شده است.
- **تشخیص خودکار مرسوله:** با ابزار هوشمند `track`، نوع کد به صورت خودکار تشخیص داده شده یا می‌توان شرکت حمل‌ونقل را دستی تعیین کرد.
- **حل خودکار و محلی کپچا:** کپچاهای عددی فرم استعلام به صورت آفلاین توسط مدل `ddddocr (beta)` در کمتر از یک ثانیه شکسته می‌شوند.
- **سیستم Fallback هیبریدی:** در صورت هرگونه اختلال موقت در درگاه اصلی، سیستم به صورت خودکار به درگاه مستقیم `tracking.post.ir` و استخر پروکسی‌های ایرانی سوئیچ می‌کند.

## 🛠 ابزارهای موجود (Tools)

| ابزار | پارامترها | توضیحات |
|---|---|---|
| `track` | `code`, `courier="auto"` | رهگیری هوشمند مرسوله (پست، تیپاکس، ماهکس، چاپار) با قابلیت تشخیص خودکار |
| `track_tipax` | `code`, `search_type="barcode"` | رهگیری اختصاصی مرسوله تیپاکس با بارکد رهگیری یا شماره قرارداد |
| `track_mahex` | `code` | رهگیری اختصاصی مرسوله ماهکس با شماره بارنامه |
| `track_chapar` | `code` | رهگیری اختصاصی مرسوله چاپار با شماره پیگیری |
| `track_many` | `codes`, `courier="auto"` | رهگیری همزمان چند مرسوله (کدها با ویرگول یا فاصله جدا شوند) |
| `status` | *بدون ورودی* | گزارش وضعیت درگاه‌ها، دسترسی جهانی، استخر پروکسی و وضعیت کپچاشکن |

## 📦 نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها
پایتون ۳.۱۰ یا ۳.۱۱ پیشنهاد می‌شود:

```bash
git clone https://github.com/mamali6/iranpost-mcp.git
cd iranpost-mcp

# ساخت محیط مجازی و نصب کتابخانه‌ها
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### ۲. اتصال به Hermes Agent

```bash
hermes mcp add iranpost --command /path/to/iranpost-mcp/.venv/bin/python --args /path/to/iranpost-mcp/server.py

# بررسی وضعیت
hermes mcp list
```

### ۳. اتصال به Claude Desktop

فایل کانفیگ کلود دسکتاپ (`claude_desktop_config.json`) را ویرایش کنید:

```json
{
  "mcpServers": {
    "iranpost": {
      "command": "/path/to/iranpost-mcp/.venv/bin/python",
      "args": ["/path/to/iranpost-mcp/server.py"]
    }
  }
}
```
